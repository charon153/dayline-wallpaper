壁纸设置

导入你的日程

  1. 在日程表应用中打开「导入课表 → 数据管理」，点击「导出全部数据」，保存 JSON 文件。
  2. 用文本编辑器打开该文件，将完整内容复制到下面，点击「导入日程」。课程、事项、学期和节次时间会一起读取。
  3. 检查学期开始日，然后通过顶部周次导航查看日程。后续应用数据改变时，重新导出并粘贴即可更新壁纸。

通过 Wallpaper Engine「从 URL 打开」加载时，先隐藏桌面图标即可直接键盘编辑。直接导入本地文件时，请在普通浏览器编辑并把导出的单行 JSON 粘贴到 Wallpaper Engine 属性。

导入内容只保存在当前设备的网站存储中，页面不会上传日程；个人数据仅在你主动导入后显示。

关于这个独立壁纸

壁纸中的课程和事项按开始、结束时间显示。点击「添加事项」可录入安排，点击已有事项可修改或删除；课程卡片可以查看详情。

壁纸使用你导入的数据，并不会自动连接学校教务系统。导入后可在壁纸内编辑事项，编辑结果不会回写原日程表应用。

这是独立网页壁纸，不提供后台系统提醒。需要 Windows 通知或提示音时，请运行原日程表应用。

重复星期

结束时间须晚于开始时间，且在同一天。每周事项从所选日期开始；每天、工作日和自定义星期按对应规则重复。导入的旧时间点事项可保留空结束时间。
